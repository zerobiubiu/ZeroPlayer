# 私有文件树取代逻辑归档

- 状态：已执行
- 影响范围：首页、文件操作、网页传输、导入与播放
- 替代：[0002 逻辑文件夹](0002-logical-folders.md)

## 背景

用户要求首页直接管理文件与目录，不再使用媒体库、收藏和播放列表的交互模型；网页也需要上传任意格式并管理同一批文件。旧实现中的文件夹只改变数据库字段，无法表示真实的多级目录。

## 决策

1. 以应用私有 `files/media/` 作为文件树根；每级展示直接子目录和文件，首页与网页通过相同仓库访问。
2. 视频、字幕和其他格式都可存放在树内。视频的元数据与播放进度仍保存在 Room，属于内部实现，不改变文件树的层次。
3. 保留旧数据库表、播放历史及现有磁盘文件，不因界面切换清除或自动搬迁用户数据。旧逻辑文件夹与播放列表不再作为界面入口。
4. 旧网页导入可能使用 UUID 作为磁盘文件名：操作和路径继续使用真实文件名，展示与下载优先使用原始显示名；用户主动重命名时才改变文件名。
5. 导入、目录操作、网页上传和外部分享都限制在应用自己的文件范围；外部来源只读，用户明确导出或分享时才向其他应用提供副本或临时读取授权。

## 后果

- 目录重命名、移动和删除必须同时维护文件及其内部媒体记录；不能沿用旧的 `folderId` 逻辑移动。
- 同目录同名字幕可以随视频加载，原有按视频 ID 存放的字幕继续支持。
- 网页服务开启期间不使用认证或令牌，任何能连接该端口的设备都可以操作文件；服务停止前应限制在可信网络使用。
- 旧版逻辑归档不会自动转换为物理目录，用户可按需要在新文件树中自行整理。
