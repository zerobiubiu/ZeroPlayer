# 0002 文件夹为逻辑归档，不映射真实目录

状态：已执行
影响范围：`core:database`、`data`、媒体库/文件夹/详情页

## 背景

需求同时要求"文件夹管理"和"移动视频"。若把文件夹映射为磁盘目录，则：

- 移动/重命名文件夹需要批量移动文件，中途失败会造成磁盘与数据库不一致；
- 同一视频不能属于多个文件夹；
- 删除文件夹需要决定"删文件还是移文件"，任何选择都伴随大批量 IO 风险。

## 决策

媒体文件一律平铺在 `files/media/`，文件夹仅存在于数据库（`folders` 表 + `media.folderId`）：

- 新建/重命名文件夹只改数据库；
- "移动到文件夹"只更新 `folderId`，不搬动文件；
- 删除文件夹把其下媒体置为"未归档"，不删除文件；
- 媒体重命名才真正改磁盘文件名，并同步 `fileName` / `relativePath`。

## 后果

- 移动操作是常数时间、原子性由数据库保证，无需回滚磁盘。
- 用户看到的"文件夹"是应用内组织方式，与应用私有存储的物理目录无关；界面文案已提示这一点。
- 未来若需要真实目录（例如导出到外部存储），可在不改变 UI 的前提下调整存储层，`folderId` 语义不受影响。
