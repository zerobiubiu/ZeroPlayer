## 一、UX Writing（14 项）

### F-01 标题与面包屑首层重复“文件”——P2——已验证
- 页面：首页（根目录与所有子目录）
- 组件：`HomeTopBar` + `DirectoryBreadcrumbs`
- 问题：顶部大标题“文件”与其正下方面包屑第一段“文件”是同义词重复，两个层级同时强调同一信息。
- 表现：标题 20sp/半粗 + 面包屑 14sp，间隔约 8dp，视觉上像两行标题。证据 `assets/home-light.png`、`assets/home-empty-dir.png`。
- 证据：`feature/home/.../HomeScreen.kt:218`、`HomeScreen.kt:254`。
- 影响：占用首屏约 40dp；削弱面包屑“当前位置”的语义，用户会把它当成页面标题的重复。
- 建议：面包屑以根目录图标或“全部文件”替代“文件”；或标题改为当前目录名，面包屑只显示层级。
- 优先级：P2

### F-02 空状态指向“加号”但存在两个加号入口，CTA 与顶栏重复——P3——已验证
- 页面：空目录
- 组件：`EmptyState`（首页调用）
- 问题：“使用右上角的加号导入文件，或新建目录。”右上角实际有“新建目录（文件夹+）”和“导入（+）”两个图标；同时下方“新建目录”按钮与顶栏第一个图标功能重复。
- 表现：文案无法确定“加号”是哪一个；两处入口做同一件事。证据 `assets/home-empty-dir.png`。
- 证据：`HomeScreen.kt:117-135`、`HomeScreen.kt:124`。
- 影响：首次使用者需要在两个相似图标间试错。
- 建议：文案改成“从右上角导入文件”或直接引导点击下方按钮；空状态只保留一个主 CTA（导入）。
- 优先级：P3

### F-03 不支持文件的提示不含文件名——P3——已验证
- 页面：首页
- 组件：Snackbar
- 问题：“此文件不支持播放，可通过操作菜单导出或分享。”没有指明哪个文件，且以否定句开头。
- 表现：点击 `说明.txt` 后底部提示。证据 `assets/home-unsupported-snackbar.png`。
- 证据：`feature/home/.../HomeViewModel.kt:95`。
- 影响：多文件列表中用户不确定哪一行被拒绝；否定式开头增加理解成本。
- 建议：“说明.txt 不是可播放的视频。可从操作菜单导出或分享。”
- 优先级：P3

### F-04 移动对话框把内部根目录名“文件”当路径展示——P2——已验证
- 页面：首页 → 移动
- 组件：`MoveDialog`
- 问题：“当前位置：文件”把内部虚拟根目录显示给用户，并省略层级符号，读起来像“当前是一个文件”。
- 表现：对话框第二行固定为“当前位置：文件/…”。证据 `assets/home-move-dialog.png`。
- 证据：`feature/home/.../HomeDialogs.kt:157`。
- 影响：用户不确定自己在哪一层、目标目录是否已选对。
- 建议：显示“当前位置：根目录”或面包屑路径；当前浏览目录高亮“在此处移动”。
- 优先级：P2

### F-05 重命名校验使用“空字符”术语——P3——已验证
- 页面：首页 → 重命名
- 组件：`NameDialog`
- 问题：“名称不能包含斜杠、反斜杠或空字符”中的“空字符”不是用户能操作的输入。
- 表现：输入 `/` 后出现红框与提示。证据 `assets/home-rename-error.png`。
- 证据：`HomeDialogs.kt:44`。

- 优先级：P3

### F-06 “导入探测”与“以播放器为准”制造不确定——P2——已验证

### F-07 码率显示原始 bps 数值——P2——已验证
- 页面：视频详情
- 组件：信息表
- 问题：显示 `3205365 bps`，未换算 Mbps、未分组。
- 表现：详情页“码率”一行。证据 `assets/detail-light.png`。

### F-09 Wi-Fi 服务的无鉴权风险埋在长段落正文——P1——已验证
- 页面：首页 → 通过 Wi-Fi 导入
- 组件：`WifiImportSheet`
- 问题：“服务没有登录或访问令牌，能访问该地址的设备均可读写文件”与普通说明合并成一段 3 句长文，没有警告色、图标或独立区块。
- 表现：启动按钮下方的 6 行灰色正文；风险句在第二句中间。证据 `assets/wifi-sheet-light.png`。
- 证据：`feature/importer/.../WifiImportSheet.kt:155`。
- 影响：用户在公共/办公网络开启服务时可能忽略风险；这是数据被同网设备读写的安全边界。
- 建议：拆成独立警示块（error/tertiary 容器 + 图标 + 一句话结论 + “仅在可信网络使用”）；启动按钮旁常驻该提示。
- 优先级：P1
- 状态：**已修复**（2026-11-13，阶段 1E）。核实服务全部路由无鉴权且绑定站点本地地址后，风险拆为独立警示块（errorContainer + WarningAmber 图标 + 标题/说明两行），位于启动按钮前并常驻，关闭/重开面板仍显示；原段落只留操作说明。未加鉴权/协议。详见 [变更记录 0015](../changes/0015-copy-layer-terminology-wifi-risk.md)。

### F-10 同名设置三套叫法，目录/文件夹混用——P1——已验证
- 页面：首页、Wi-Fi 面板、设置·导入
- 组件：多处文案
- 问题：
  - 缩略图设置：设置页“导入时生成缩略图”/Wi-Fi 面板“生成视频缩略图”/内部字段 `IMPORT_THUMBNAILS`；
  - 查重设置：设置页“检测疑似重复视频”/Wi-Fi 面板“检测重复视频”；
  - 目录：顶栏“新建目录”、空状态“此目录为空”、详情“相对路径”、面包屑“文件”，而文件管理器惯例是“文件夹”。
- 表现：同一开关在两处出现且名称不同（`assets/wifi-sheet-light.png` vs `assets/settings-导入.png`）。证据：`WifiImportSheet.kt:167,174`、`SettingsScreen.kt` 导入段、`HomeScreen.kt:124`。
- 影响：用户会怀疑它们是不同功能；术语不稳定也直接影响搜索与帮助文档。
- 建议：建立术语表（目录统一为“文件夹”或反之），同一设置只保留一个名称与一个入口。
- 优先级：P1
- 状态：**已修复**（2026-11-13，阶段 1E）。用户可见容器统一“文件夹”（技术路径保留“目录”）；两个导入开关文案只在 core/design 定义一次，设置页与 Wi-Fi 面板共同引用；播放模式“目录循环”改“文件夹循环”。术语黑名单纳入文案门禁。详见 [变更记录 0015](../changes/0015-copy-layer-terminology-wifi-risk.md)。

### F-11 标点、单位与括号格式不一致——P3——已验证

- 组件：多段文案

### F-12 导入通知被合并成一段，失败原因直出原始错误——P2——已验证（代码）
- 页面：导入任务对话框
- 组件：`ImportTasksDialog`
- 问题：所有通知 `joinToString("\n")` 塞进一个 `Text`；失败任务直接展示 `task.errorMessage`。

### F-13 局域网权限拒绝后没有恢复路径——P2——已验证（代码）
- 页面：Wi-Fi 导入浮层
- 组件：`WifiImportSheet`

### F-14 全部文案硬编码，无 `stringResource` 与 i18n 层——P1——已验证
- 页面：全项目
- 组件：所有界面
- 问题：`app/src/main/res/values/strings.xml` 只有 `app_name`；主代码中文字面量 767 处；`stringResource(` 使用 0 次；无 `values-en`。
- 证据：全仓统计（`grep` 767 条中文串、0 次 `stringResource`）、`app/src/main/res/values/strings.xml`。
- 影响：无法做多语言；文案无法统一审校；标点/术语不一致难以批量修复；Android 无障碍的文本替换能力也受限。
- 建议：建立 `strings.xml` 文案层（含复数/占位符），先迁移高频页面；加 lint/CI 检查禁止新增硬编码；确定是否支持英文。
- 优先级：P1
- 状态：**已修复**（2026-11-13，阶段 1E）。按模块建立中文 strings.xml（core/design、domain、五个 feature、app），UI 模块用户可见文案全部经 stringResource/Context.getString 引用；ViewModel 消息改为“资源+参数”模型；新增 CopyResourceGateTest 门禁（硬编码白名单扫描+术语黑名单+同源断言）。数据层错误原因文案列为剩余范围（2D 处理），内部字符串逐条登记。仅中文资源化，不建 values-en。详见 [变更记录 0015](../changes/0015-copy-layer-terminology-wifi-risk.md)。

### F-16 面板每一行都带勾选图标，视觉上像“全部已选中”——P1——已验证
- 页面：播放器 → 倍速/画面比例/音轨面板
- 组件：`ActionSheet` + `SheetAction.icon`
- 问题：所有条目都传 `Icons.Outlined.Check`（含未选中项），只有文案里的“（当前）”区分状态。

- 建议：未选项不显示前导图标或使用中性图标；当前项用勾+高亮容器；或改为 RadioButton/`selectable` 语义。
- 优先级：P1
- 状态：**已修复**（2026-11-12，阶段 1B）。`SheetAction` 引入语义类型，仅当前单选项显示勾选并高亮，动作/导航/状态不显示勾选；读屏带单选语义。详见 [变更记录 0012](../changes/0012-player-panels.md)。

### F-17 “更多”面板中的禁用“播放引擎”行抢占视觉重点——P2——已验证

## 三、Information Architecture（5 项）

### F-18 设置一级把“配置/信息/清理动作”混为同级——P2——已验证
- 页面：设置一级
- 组件：`SettingsHubScreen`
- 问题：7 个入口按页面切分，其中“显示”只有一个主题选项、“关于”是纯信息、“存储”是信息+清理动作，却与“播放/字幕/手势/导入”这些多选项配置组同级。
- 表现：`assets/settings-hub-light.png`；进入“显示”后仅一个下拉（`assets/settings-显示.png`）。
- 证据：`SettingsScreen.kt:73-80`、`:100`。
- 影响：点击成本与内容量不匹配；两个入口只为看一行字。
- 建议：一级按任务分组（播放与字幕 / 手势与反馈 / 外观 / 数据与存储 / 关于），把单选项并入相邻页；关于页独立入口放底部或顶栏。
- 优先级：P2

### F-19 顶栏旋转图标打开的是“画面比例”，旋转藏在“更多”——P1——已验证
- 页面：播放器
- 组件：`PlayerTopBar` + 面板
- 问题：顶栏第二个图标是 `ScreenRotation`（旋转语义），实际打开“画面比例”；真正的“旋转屏幕”在“更多”面板第二层。
- 表现：图标与结果不一致；旋转需两次点击。证据 `assets/player-portrait.png`、`assets/player-aspect-sheet.png`、`assets/player-more-sheet.png`。
- 证据：`PlayerScreen.kt:386`（`onOpenAspect`）、`:572`（旋转项）。
- 影响：用户按图标预期点击会被带到错误面板；旋转这一高频操作被降级。
- 建议：图标换成 AspectRatio 或文字标签“比例”；旋转提为顶栏按钮或长按顶栏图标。
- 优先级：P1
- 状态：**已修复**（2026-11-12，阶段 1C）。比例入口改用 AspectRatio 图标（描述“画面比例”）打开比例面板；旋转提为顶栏独立按钮（描述“旋转屏幕”）一次点击切换横竖屏；“更多”面板删除旋转行，全应用仅一个旋转入口。详见 [变更记录 0013](../changes/0013-player-entries-queue.md)。

### F-20 “播放列表”面板没有列表——P1——已验证
- 页面：播放器
- 组件：`ActionSheet`（队列）
- 问题：面板只有“上一集/下一集”和 4 个播放模式，没有队列条目、当前项高亮或跳转。
- 表现：标题“播放列表 · 2/2”，内容与标题不符。证据 `assets/player-queue-sheet.png`。
- 证据：`PlayerScreen.kt:574-620`。
- 影响：用户无法查看接下来播什么、无法跳到某一集；“列表”承诺落空。
- 建议：面板上半部渲染队列（当前项高亮、点击跳转），下半部放播放模式；或把入口改名“播放模式”。
- 优先级：P1
- 状态：**已修复**（2026-11-12，阶段 1C）。入口与面板更名“播放队列”，渲染真实队列条目（仅文件名）、当前项高亮带勾、点击经受控 API 跳转（无效/重复/连点无操作）；打开自动定位当前项，限高滚动，空队列空状态；上一集/下一集与播放模式保留。详见 [变更记录 0013](../changes/0013-player-entries-queue.md)。
