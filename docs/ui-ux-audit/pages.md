# 逐页面审查

覆盖 11 个页面、8 类弹层、3 类状态。截图位于 `assets/`；问题编号对应 `findings.md`。

---

## 1. 首页文件树（`home`）

- **职责**：浏览应用私有目录，进入子目录，播放视频，长按/菜单管理文件，导入入口。
- **当前信息结构**：顶栏（标题“文件”、新建目录、导入菜单）→ 面包屑 → 文件/目录列表 → 底部导航（首页、设置）→ 导入任务 FAB（有任务时）。
- **文案问题**：F-01 标题与面包屑重复；F-02 空状态“右上角的加号”指代不明且 CTA 重复；F-03 不支持文件提示不含文件名；F-10 “目录”与系统惯例“文件夹”不一致。
- **视觉问题**：F-28 每行三点菜单噪声；F-23 目录行只显示“目录”占位；F-24 顶部标题+面包屑约 120dp。
- **布局问题**：两行列表对目录无信息增益；面包屑使用 `TextButton` 造成额外高度；底部导航与内容底部留白尚可。
- **组件问题**：F-30 自建 `TopAppBar`；`ListItem` 使用规范；行菜单未分组（F-22）。
- **交互问题**：无多选/批量（F-41）；点击非视频文件只给 Snackbar；长按与三点菜单双入口重复；`BackHandler` 仅在子目录启用，行为正确。
- **可访问性问题**：行 `combinedClickable` 提供 onClickLabel/onLongClickLabel；三点按钮描述包含文件名（好）；开关类问题不涉及；触控目标均 ≥48dp。
- **优化方向**：合并标题与面包屑；目录行单行或显示条目数；隐藏/弱化行尾菜单；补多选与批量；统一术语。
- **截图**：`home-light.png`、`home-empty-dir.png`、`home-breadcrumb.png`、`home-row-menu.png`、`home-dark.png`、`home-font130.png`、`home-error-state.png`。

## 2. 视频详情（`detail/{mediaId}`）

- **职责**：展示单个视频的元数据、播放入口、外挂字幕管理、文件信息。
- **当前信息结构**：顶栏（返回、标题“视频详情”、文件信息）→ 16:9 封面 + 中央播放按钮 + 进度条 → 标题 → 3 个 chips → 观看进度文案 → “视频信息”12 行 → 外挂字幕计数与列表 → 私有存储说明卡。
- **文案问题**：F-06 导入探测/以播放器为准；F-07 bps；F-08 同类技术泄漏（私有存储说明偏长）；"暂无播放进度"否定式；F-11 括号格式。
- **视觉问题**：F-15 chips 与表格重复；标题层级合理；播放按钮覆盖封面中心，弱化了封面内容。
- **布局问题**：F-25 12 行信息表无分组；16:9 封面在竖屏占高约 200dp，首屏只看到标题与 chips。
- **组件问题**：`AppTopBar`、`InfoRow`、`MetaChip` 使用一致；播放按钮 `Button` 48dp 合规。
- **交互问题**：缺少重命名/移动/删除/导出/分享（F-21）；“添加”字幕打开 `*/*` 选择器，与文案声明的 srt/ass/ssa/vtt 不符；字幕删除有确认对话框（好）。
- **可访问性问题**：封面 `AsyncImage` 无描述（装饰性可接受）；播放按钮有文本；信息行为纯文本，读屏可读；字幕删除按钮有 `contentDescription`（好）。
- **优化方向**：补齐文件操作；拆分信息表分组；chips 与表格去重；字幕选择限定 MIME 类型；压缩私有存储说明。
- **截图**：`detail-light.png`、`detail-scrolled.png`、`detail-file-info.png`。

## 3. 播放器（`player/{mediaId}`）

- **职责**：全屏播放、手势控制、字幕/音轨/比例/倍速/队列、锁定、后台播放会话。
- **当前信息结构**：视频层（SurfaceView）→ 顶部（返回、文件名、画面比例、字幕、更多）→ 中央手势反馈 → 底部（时间/剩余、进度条、倍速、快退、播放/暂停、快进、播放列表）→ 各面板 → 锁定提示 → 错误条 → 播放结束重播。
- **文案问题**：F-11 字幕面板单位/括号；“更多”内“播放引擎”技术说明（F-17）；面板标题“播放列表”名不副实（F-20）。
- **视觉问题**：F-16 每行勾选图标；F-17 禁用技术行；进度条滑块为竖直条 + 末端小圆点，与常见圆形滑块不一致（M3 默认样式，记录为视觉一致性问题，未单列）。
- **布局问题**：底栏三行（时间、滑块、操作）在小屏横屏时占用约 96dp；顶部控件已按 `safeDrawing` 避让（好）；F-27 横屏撕裂（待验证）。
- **组件问题**：F-34 完全绕开 Token（间距/蓝色）。F-35 图标风格混用。
- **交互问题**：F-19 旋转入口错位；F-20 播放列表无列表；F-38 面板弹出时状态栏出现；控制层 4 秒自动隐藏（暂停时不隐藏，合理）；双击/长按/滑动均有反馈。
- **可访问性问题**：所有图标有 `contentDescription`；F-36 速度胶囊 32dp、传输键 44dp、锁定 chip ~34dp；滑块有“播放进度”语义；锁定提示可点击解锁。
- **优化方向**：旋转/比例归位；播放列表渲染队列；面板内重新隐藏系统栏；统一强调色与控件尺寸；删除禁用技术行。
- **截图**：`player-portrait.png`、`player-landscape.png`、`player-landscape-2.png`、`player-locked.png`、`player-more-sheet.png`、`player-subtitle-sheet.png`、`player-speed-sheet.png`、`player-queue-sheet.png`、`player-aspect-sheet.png`。

## 4. 设置一级（`settings`）

- **职责**：按类型进入设置二级页，展示当前配置摘要。
- **当前信息结构**：顶栏（设置、副标题“按类型进入二级页面调整”）→ 分组“偏好设置”→ 7 个卡片入口（图标、标题、摘要、箭头）。
- **文案问题**：副标题解释页面结构，属于实现描述；“步长 100ms”“查重开”“震动开”等摘要偏内部术语（F-10 相关）。
- **视觉问题**：卡片间距、图标与摘要层级合理；7 项一屏略满，但可滚动。
- **布局问题**：单一分组承载全部入口；F-18 配置/信息/动作混合。
- **组件问题**：`SettingsEntryRow`（Surface+chevron）与 `ClickableSettingRow`（无箭头、值用主色）并存，前者是后者的替代但旧组件未删（F-31）。
- **交互问题**：点击区域整卡（≥72dp，合规）；无二次确认需求。
- **可访问性问题**：卡片可点击且带箭头语义；摘要为 12sp（≥12）；读屏按标题+摘要顺序可读。
- **优化方向**：组内按任务再分块；将“关于”移出配置组；摘要改为用户语言。
- **截图**：`settings-hub-light.png`、`settings-hub-dark.png`、`settings-hub-font130.png`。

## 5. 设置·播放（`settings/playback`）

- **职责**：自动播放/记忆进度/续播、默认倍速、默认比例、双击步长、长按倍速。
- **信息结构**：顶栏（播放、副标题“续播、倍速与画面比例”）→ “播放行为”3 开关 → “播放参数”3 数值 + 1 下拉。
- **文案问题**：F-29 “允许范围”常驻；F-10 “步长”属于内部术语；“打开时自动续播”与“记忆播放进度”关系需要推理（依赖关系未说明）。
- **视觉问题**：开关行与数值行高度差约一倍（F-26）；下拉值用主色 + 下拉箭头，与其他页箭头风格不同。
- **布局问题**：三个数值行占满一屏，滚动明显。
- **组件问题**：`SwitchRow`、`NumericSettingRow`、`SettingsDropdownRow` 三种交互模型共存（F-37）。
- **交互问题**：F-37 即时 vs 保存；数值保存按钮禁用态像普通文本；离开页面未保存即丢失。
- **可访问性问题**：输入框有 label 与错误 supportingText（关联正确）；保存按钮有 `contentDescription`；F-33 开关双目标。
- **优化方向**：统一即时保存；数值改用底部面板/步进器；说明“续播依赖记忆进度”。
- **截图**：`settings-播放.png`、`settings-playback-font130.png`。

## 6. 设置·字幕（`settings/subtitle`）

- **职责**：字号、背景、颜色、延迟步长。
- **信息结构**：顶栏 → “字幕样式”3 项 + 说明 → “字幕同步”1 项 + 说明。
- **文案问题**：说明段“ASS 等自带样式的字幕保留原排版”有用但偏技术；“延迟调节步长”术语（F-10）；F-11 单位空格。
- **视觉问题**：同上数值行过高；说明文字 12sp 灰色，两段结尾都带解释，页面显得“文档化”。
- **布局问题**：4 个控件 + 2 段说明，滚动少；密度可接受。
- **组件问题**：与播放页同组件，问题一致。
- **交互问题**：“会记住每个视频的字幕”是信息提示，位置在页面底部，用户可能错过（与 F-21 字幕管理相关）。
- **可访问性问题**：同播放页。
- **优化方向**：合并说明；字幕记忆提示放到字幕面板首次使用时；术语统一“字幕延迟”。
- **截图**：`settings-字幕.png`。

## 7. 设置·手势（`settings/gesture`）

- **职责**：四个手势开关 + 震动反馈开关。
- **信息结构**：顶栏 → “手势开关”4 项 → “反馈”1 项。
- **文案问题**：开关标题较长（“左侧上下滑动调节亮度”），但描述准确；只有“横向滑动调节进度”带说明，其余为 null，密度不一致。
- **视觉问题**：4 个开关无分组图标；“反馈”单独一组只放一个开关，分组收益低。
- **布局问题**：行高统一 56dp 左右，密度合理。
- **组件问题**：`SwitchRow` 一致（F-33 双目标）。
- **交互问题**：无“手势说明/示意”，新用户不知道滑动阈值与倍速逻辑；震动开关依赖设备能力，但未显示“本机不支持”的状态。
- **可访问性问题**：F-33；开关标题即标签，读屏可读。
- **优化方向**：合并“反馈”到手势组；为复杂手势加一次图示说明（首次进入可折叠）；检测 vibrator 能力并在不支持时置灰。
- **截图**：`settings-手势.png`。

- **布局问题**：页面高度浪费；页面本可与“关于”或“手势”合并。
- **组件问题**：`SettingsDropdownRow` 正常。
- **交互问题**：选择即时生效（正确）；无预览。
- **可访问性问题**：下拉有描述（“展开主题模式选项”）；对比度通过。
- **优化方向**：并入“外观”页，增加字号/显示密度等真正可调项；删除实现说明。
- **截图**：`settings-显示.png`。

## 10. 设置·存储（`settings/storage`）

- **职责**：展示媒体/缩略图/临时文件/可用空间，清理缓存。
- **信息结构**：顶栏 → 卡片（4 行数据 + 分隔线 + 2 个描边按钮 + 说明）。
- **文案问题**：“文件”行值为“2 个视频”，单位与标签不一致；F-10 术语；“清理缩略图/清理临时文件”未说明影响范围（说明段有补充）。
- **视觉问题**：数据行与按钮同卡，层级合理；按钮为 OutlinedButton（次要动作），符合危险度。
- **布局问题**：卡片后大量空白；可增加按目录占用分布。
- **组件问题**：`InfoRow` + `OutlinedButton`，无重复实现。
- **交互问题**：清理无确认（影响小，可接受）；结果通过 Snackbar 反馈（好）；无“正在清理”加载态。
- **可访问性问题**：按钮有文本；数据行读屏按“标签+值”输出。
- **优化方向**：增加清理中的禁用/进度；说明“不会删除视频与待恢复任务”前置到按钮附近。
- **截图**：`settings-存储.png`。

## 11. 设置·关于（`settings/about`）

- **职责**：版本、播放引擎、许可与产品说明。
- **信息结构**：顶栏 → “版本信息”3 行 → “说明”2 段。

- **视觉问题**：引擎状态右对齐占三行，破坏 `InfoRow` 的“标签-短值”节奏；大段文字后大面积空白。

- **组件问题**：`InfoRow` 被用于长文本（超出组件设计假设）。

- **可访问性问题**：长文本可读；无链接可聚焦。
- **优化方向**：版本一行 + 复制；引擎信息移入诊断页；许可放到独立可滚动页或网页链接。

## 12. 弹层与对话框

### 12.1 文件行菜单（`home-row-menu.png`）
- 6 项平铺、仅一条分隔线；危险项红字但与其它项同区块（F-22）；菜单无图标；长按与三点双入口。
- 方向：按“信息/传输/管理/危险”分组；危险项独立区。

### 12.2 新建目录（`home-create-dialog.png`）
- 标题“新建目录”、字段 label“名称”、取消/创建；创建按钮在空输入时禁用。
- 问题：没有显示父目录；label 过于笼统；F-05 的非法字符提示在出错后才出现。
- 方向：标题带当前目录；label 改“文件夹名称”；实时校验。

### 12.3 重命名（`home-rename-error.png`）
- 错误态红框 + “名称不能包含斜杠、反斜杠或空字符”；保存禁用。
- 问题：错误文案术语（F-05）；键盘遮挡下对话框上移，按钮仍可见（好）。
- 方向：错误文案示例化；支持自动去掉非法字符。

### 12.4 移动（`home-move-dialog.png`）
- 标题“移动“sample-a.mp4””、当前位置、返回上级、目录列表、取消/移动到此处。
- 问题：F-04 内部根名；目录项点击即进入，选中态不可见；确认按钮禁用条件为“与原始父目录相同”，用户不易理解。
- 方向：显示面包屑路径；当前目录高亮“在此处移动”；选中目标用勾选标记。

### 12.5 删除确认（`home-delete-dialog.png`）
- 标题“删除文件？”、正文含文件名与不可撤销说明、取消/红色删除。
- 问题：文案清晰；与通用 `ConfirmDialog` 重复实现（F-32）。
- 方向：复用通用组件；目录删除可加数量摘要。

### 12.6 Wi-Fi 导入（`wifi-sheet-light.png`）
- 标题、状态、初始目录、空间/端口、启动服务、长说明、导入设置、本次上传。
- 问题：F-09 风险埋没；F-10 设置命名不一致；F-13 权限恢复；F-40 复制反馈；“初始目录：/”与端口对普通用户是技术信息（F-15 in findings 编号为 F-04 同类）。
- 方向：安全提示升级；技术信息折叠；“导入设置”与全局设置去重；权限拒绝提供“去设置”。

### 12.7 文件信息浮层（`detail-file-info.png`）
- 标题“文件信息” + 文件名 + 6 行键值（相对路径、绝对路径、存在、大小、MIME、缩略图）。
- 问题：绝对路径换行 3 行右对齐、可读性差；缩略图显示哈希文件名；无复制按钮。
- 方向：长路径左对齐折行 + 复制；缩略图显示“已生成/未生成”。

### 12.8 播放器面板（5 个）
- 更多：可用项与技术禁用项混排（F-17）；旋转入口（F-19）。
- 字幕：关闭字幕带勾；无轨道时提示去详情页导入；单位格式（F-11）；面板内系统状态栏出现（F-38）。
- 倍速/比例/音轨：所有项带勾（F-16）。
- 播放列表：无列表（F-20）；模式行图标全部相同。
