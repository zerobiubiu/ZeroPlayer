# UI/UX 整改实施计划（第一阶段规划，未修改代码）

状态：规划完成，等待执行指令。输入：`docs/ui-ux-audit/` 的 41 项问题（F-01～F-41）与 16 条建议（R-01～R-16）。本阶段只新增规划文档，**未修改任何源码、样式、设计 Token、翻译或配置，未提交 Git**。

配套文档：`task-breakdown.md`（41 项逐项任务）、`dependency-map.md`（依赖关系）、`validation-matrix.md`（设备与测试矩阵）、`acceptance-criteria.md`（分阶段验收）。

## 一、目标与边界

### 目标

1. 在不扩大产品功能范围的前提下，关闭审计中 **40 项已验证问题**，并把 1 项待验证问题（F-27）转为“已确认缺陷”或“关闭（附证据）”。
2. 建立可持续的文案层与组件约定，避免同类问题回流。
3. 所有改动可编译、可回归、可截图比对，且不破坏播放器、导入/导出、私有文件树的核心行为。

### 不做

- 不新增产品功能（不恢复媒体库/网格首页、不新增网络媒体、不增加“检查更新”等未在审计中的能力）。
- 不因为“统一 Token”而重写播放器的深色媒体语境；只统一来源与取值。
- 不机械迁移全部 767 条硬编码文案；按页面分批，先高频与本次改动区域。
- 不把主观视觉偏好（如是否使用品牌字体、滑块形状）当作缺陷处理；F-35 只收敛已有规则冲突。
- 不在本阶段提交/推送 Git。

## 二、阶段划分与理由

原建议按 P1 → P2 → P3 推进。实际依赖分析后做两处调整：

1. **F-22（文件菜单分组）提前到阶段 1**：F-21 要给详情页加同一组文件操作，若先做详情再改菜单，会返工两次。
2. **F-17（更多面板禁用技术行）提前到阶段 1**：与 F-19（入口归位）同属播放器“更多”面板，一次改完避免重复打开同一文件。

除此之外保持“先行为、后视觉、最后细节”的顺序。

## 三、关键依赖（摘要，详见 `dependency-map.md`）

```
术语表 ─→ i18n 资源层 ─→ 各页面文案迁移
设置保存模型 ─→ 设置页重组 ─→ 数值表单/范围提示
文件菜单分组 ─→ 详情页文件操作 ─→ 多选批量
ActionSheet 选中语义 ─→ 播放器 4 个面板
播放器 Token ─→ 触控目标/图标规则 ─→ 横屏复验
```

- **公共组件先于页面**：`ActionSheet`、`SwitchRow`、`ErrorState`、`AppTopBar`、`ConfirmDialog` 的接口变更必须先落地，页面再接入，避免同一文件反复改动。
- **文案决策先于 i18n**：术语未定就迁移资源会产生大量返工；先定术语表，再迁移 P1 页面，最后扩展。
- **播放器行为先于视觉**：先修 F-16/F-19/F-20/F-38 的行为与语义，再做 F-34/F-36 的 Token 与尺寸，最后跑横屏矩阵。
- **文件操作先于多选**：单文件路径与确认语义稳定后，批量才有可靠的失败处理模型。

## 四、风险清单

| 风险 | 涉及 | 说明与缓解 |
|---|---|---|
| 删除/移动正在播放的媒体 | F-21、F-41 | 播放会话持有文件路径；详情页删除当前媒体必须停止播放并清理队列。先补测试：详情删除当前项→播放器回首页且服务释放。 |
| 批量操作部分失败 | F-41 | 逐项结果汇总，不能“全成功/全失败”一刀切；失败项保留并显示原因；禁止静默跳过。 |
| i18n 资源归属 | F-14 | 各 feature 模块无法引用 `app` 的资源；需按模块建立 `strings.xml`。共享组件（`AppTopBar` 的“返回”等）改为参数或资源由调用方传入。 |
| 即时保存写放大 | F-37 | 连续输入/滑块会频繁写 DataStore；需防抖或提交时机控制；失败要提示。 |
| 开关语义修改回归 | F-33 | `toggleable` 合并语义可能影响现有 UI 测试与读屏顺序；需同步更新测试。 |
| 面板沉浸式厂商差异 | F-38 | 状态栏隐藏/恢复在不同 OEM 上行为不同；以 `WindowInsetsController` 统一，并在真机矩阵验证。 |
| 队列跳转范围蔓延 | F-20 | 当前 `playQueueIndex` 为私有，任意跳转需新增受控 API。默认只展示队列与当前项；跳转需产品确认后单列。 |
| 横屏根因未定 | F-27 | 模拟器 SwiftShader/Surface 可能造成伪缺陷；未真机确认前不重构渲染链路。 |
| 死组件删除决策 | F-31 | `MediaCardData` 与已下线媒体库相关；删除前确认无后续计划；否则标注 deprecated。 |
| 文案迁移面过大 | F-14 | 分批迁移，先 P1 涉及页面；全量迁移不在本阶段。 |
| 平板支持承诺 | F-18/整体 | 当前无响应式布局；若承诺平板，需要独立范围，不在本次整改内默认包含。 |
