# 验证矩阵

目标：用可重复的测试覆盖 41 项整改，并保证播放器、文件管理、导入/导出等核心链路不因 UI 修改回归。区分**可自动化**与**必须人工**两类。

## 1. 测试层级与命令

| 层级 | 命令/方式 | 适用范围 | 备注 |
|---|---|---|---|
| 编译 | `./gradlew :app:assembleDebug :app:lintDebug` | 每阶段门禁 | 需要 JDK 17+、Platform 37、Build-Tools 36 |
| JVM 单测 | `./gradlew testDebugUnitTest` | 格式化、校验、VM 逻辑、状态映射 | 现有 12 个测试文件 |
| Compose UI 测试 | `./gradlew :app:connectedDebugAndroidTest -PallowDestructiveConnectedTests=true` | 面板选中、开关语义、触控尺寸、导航 | **仅可丢弃模拟器**；任务结束会卸载应用 |
| 现有仪器化回归 | 同上，按类过滤 | 文件树一致性、导入、传输、播放、媒体会话 | 见下表 |
| 手工 E2E | 按 `pages.md` 流程 | SAF、通知、横屏、TalkBack、平板 | 不可自动化或用例成本高 |
| 截图对比 | `adb exec-out screencap` + 固定页面状态 | 所有改动页面 | 浅/深色、1.3 字号各一组 |

**设备测试警告**：`connected*AndroidTest` 会卸载应用并清空私有媒体；只在可丢弃模拟器运行，必须显式加 `-PallowDestructiveConnectedTests=true`。真机验证不得直接运行该任务。

## 4. 功能回归矩阵

### 4.1 播放器（不可只做 UI 截图）

| 用例 | 步骤 | 自动化 |
|---|---|---|
| 播放/暂停 | 打开视频→暂停→继续 | `MpvPlaybackInstrumentedTest` 可覆盖部分；手测补充 |
| 切轨/字幕 | 选择音轨/字幕→重开视频恢复 | 手测 + 现有字幕记忆验证 |
| 进度/手势 | 双击、横向滑动、底部滑块 | 手测（速度分档） |
| 后台/锁屏 | 播放→Home→通知栏控制→锁屏控制 | 手测（D2–D4） |
| 退出即停止 | 播放→返回→服务/通知消失 | `MediaSessionLifecycleInstrumentedTest` + `dumpsys` |
| 横屏 | 旋转→播放≥5 分钟→再旋转 | 手测（F-27） |
| 面板沉浸式 | 逐个打开 5 个面板→检查状态栏 | 截图 + `dumpsys window` |
| 触控尺寸 | 速度/传输/锁定控件 | Compose UI 测试读取 bounds |

### 4.2 文件管理

| 用例 | 步骤 | 自动化 |
|---|---|---|
| 新建/重命名/移动/删除（单文件） | 首页逐项操作 | `FileTreeConsistencyInstrumentedTest`、`FileTransferInstrumentedTest` |
| 详情页操作（新增） | 详情页执行五项操作 | 新增 UI 测试 + 手测 |
| 删除当前播放项 | 播放→详情删除→返回 | 新增手测/仪器化 |
| 移动后数据库一致性 | 移动→首页→详情路径 | 现有一致性测试扩展 |
| 多选批量（新增） | 选择 3 项→删除/移动→失败项 | 新增 VM 单测 + 仪器化 |
| 原始文件不变 | 导入/导出/分享后哈希对比 | 手测脚本（`sha256sum`） |

### 4.3 导入/导出（SAF）

| 用例 | 步骤 | 自动化 |
|---|---|---|
| 单文件导入 | SAF 选择→进度→完成 | 手测；`ImportCopierInstrumentedTest` 覆盖复制器 |
| 多文件导入 | 多选→队列→逐个完成 | 手测 |
| 大文件/取消/重试 | 数 GB 文件→取消→重试 | 手测（真机） |
| 导入失败 | 来源删除/空间不足 | 手测 + 错误文案检查 |
| 导出到 Downloads/Drive | 详情/首页导出→选择目标 | 手测（D1–D4） |
| 分享 | 系统分享面板→目标应用可读 | 手测 |
| 外部打开 | 文件管理器打开视频→复制→播放 | `ExternalImportInstrumentedTest` + 手测 |

### 4.4 设置与导航

| 用例 | 步骤 | 自动化 |
|---|---|---|
| 保存模型 | 修改数值→退出→重进 | Compose UI 测试 |
| 开关语义 | TalkBack 聚焦一次 | 手测 |
| 分组导航 | 每个一级入口→二级→返回 | Compose UI 测试 |
| 进程重建 | 设置页旋转/后台回收后返回 | 手测 |
| 深链/旧路由 | 旧 `settings/{section}` 兼容（若保留） | 手测 |

### 4.5 通知/锁屏

| 用例 | 步骤 | 自动化 |
|---|---|---|
| 媒体通知 | 播放→下拉控制中心→播放/暂停/上一集/下一集 | 手测 |
| 锁屏控制 | 锁屏→媒体控件→播放/暂停 | 手测（F-27 后复验） |
| 通知消失 | 返回关闭播放→通知消失 | `dumpsys` + 截图 |
| 蓝牙/耳机按键 | 连接设备→按键 | 手测（如设备可得） |

## 6. 自动化 vs 人工

**可自动化**：

- 编译、Lint、JVM 单测。
- Compose UI：面板选中、开关语义、触控尺寸、设置保存、导航、详情操作入口。
- 仪器化：文件树一致性、导入复制器、传输、播放器基础、媒体会话生命周期。
- 对比度计算、文案扫描（硬编码/术语）。

**必须人工**：

- SAF 选择器交互（系统 UI）、导出目标、分享目标。
- 通知栏/锁屏/蓝牙按键。
- 横屏渲染真伪（F-27）。
- 平板/折叠屏/挖孔屏布局与系统栏。
- TalkBack 朗读顺序与语气。
- 性能/流畅度（大目录、长队列、4K 播放）。

## 7. 证据规范

- 截图命名：`<page>-<state>-<theme>-<font>.png`，如 `player-more-sheet-dark-1.3.png`。
- 每张截图记录：设备、API、方向、主题、字号、构建号。
- before 基线使用 `docs/ui-ux-audit/assets/`；after 存 `docs/ui-ux-audit/implementation/evidence/`（执行阶段创建）。
- 失败用例必须保留日志（logcat 片段、`dumpsys` 输出）与复现步骤。
