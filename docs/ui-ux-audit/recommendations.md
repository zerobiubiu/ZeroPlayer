# 优化建议（未实施）

按依赖关系分阶段。每项标注关联问题（`findings.md`）、动作、预期结果、工作量（S ≤ 半天、M ≤ 2 天、L > 2 天，按单人估计）与验收方式。**本文件不包含代码实现**。

原则：

- 先修“用户每天都会遇到且改动小”的问题，再做结构性重构。
- 不新增页面，优先合并/收敛；不照搬 iOS 视觉；播放器保持深色独立语境。
- 所有改动都应能在现有 1080×2400 / 420dpi、深色、1.3 倍字号下回归。

---

## 阶段 0：低成本高收益（先做）

### R-01 统一设置的保存模型
- 关联：F-37、F-29、F-26
- 动作：选定“即时保存”（推荐）或“页面级保存”其中一种；数值输入改为失焦/键盘完成后保存，删除每行的“保存”按钮；范围提示仅在聚焦或出错时出现。
- 预期：用户不再怀疑改动是否生效；设置页密度提升约 30%。
- 工作量：S
- 依赖：无
- 验收：修改任意数值后直接返回，重进页面值保留；TalkBack 不出现无名称的“保存”按钮。

### R-02 修正播放器面板语义与沉浸式
- 关联：F-16、F-38、F-20、F-17
- 动作：`ActionSheet` 增加 `selected` 概念——未选中项不显示勾；当前项高亮；面板出现后重新隐藏系统栏；删除“播放引擎”禁用行；把队列条目渲染进“播放列表”。
- 预期：面板不再像“全选”；状态栏不再压住画面；播放列表名副其实。
- 工作量：S–M
- 依赖：无
- 验收：打开倍速/比例面板时只有当前项带勾且高亮；面板打开期间无电池/时间图标；播放列表面板点条目可跳转（若实现跳转）。

### R-03 修正旋转与画面比例入口
- 关联：F-19
- 动作：顶栏图标改为“比例”语义（AspectRatio 或文字“比例”）；“旋转屏幕”提升为顶栏按钮或面板首项；保留面板内的比例选择。
- 预期：一次点击到达预期结果。
- 工作量：S
- 依赖：无
- 验收：点击顶栏图标打开比例；旋转入口一次点击生效。

### R-04 首页信息层级与菜单分组
- 关联：F-01、F-02、F-22、F-23、F-24、F-28
- 动作：标题即当前目录名（或面包屑替代标题）；目录行改单行或显示条目数；行菜单按“信息/传输/管理/危险”分组；弱化行尾三点（仅选中或长按显示）。
- 预期：首屏多出约 1–2 行内容；误点危险操作概率下降。
- 工作量：S–M
- 依赖：R-01（同一批设置/列表交互调整）
- 验收：根目录与子目录均无“文件/文件”重复；目录行高度与文件行一致或信息有效；菜单分组清晰。

## 阶段 1：文案体系与安全表达

### R-05 建立文案资源与术语表
- 关联：F-14、F-10、F-11
- 动作：建立 `strings.xml`（含占位符与复数）；先迁移首页、设置、播放器、Wi-Fi 四个高频区域；确定术语表（目录/文件夹二选一、缩略图/查重/字幕/延迟统一）；加 lint/CI 检查禁止新增中文硬编码。
- 预期：文案可审校、可翻译；同名设置只有一种叫法。
- 工作量：M
- 依赖：无（可与阶段 0 并行）
- 验收：`stringResource` 覆盖目标页面；全仓新增中文硬编码为 0；术语表中每个词只有一个写法。

### R-06 安全与权限提示升级
- 关联：F-09、F-13
- 动作：Wi-Fi 风险独立为警示块（图标 + 一句话 + “仅在可信网络使用”）；启动服务按钮旁常驻；权限拒绝提供“去设置”跳转并说明权限用途。
- 预期：用户在开启服务前明确知道同网设备可读写文件。
- 工作量：S
- 依赖：R-05（文案资源）
- 验收：风险提示在按钮可见区域内；拒绝权限后可一键进入应用设置页。

### R-07 技术信息与错误文案归位
- 关联：F-05、F-06、F-07、F-08、F-12、F-39
- 动作：码率换算 Mbps；轨道信息只显示播放器真实结果；“导入探测”移入文件信息；关于页只保留版本与引擎名，诊断/许可另设入口；导入通知逐条渲染，原始错误折叠；错误态增加标题与“返回上级”。
- 预期：用户界面不再出现 `libplayer.so`、`assets/...`、`bps`、`空字符`。
- 工作量：M
- 依赖：R-05
- 验收：全量文案扫描无实现细节；错误页两个动作均可执行；通知可逐条阅读。

## 阶段 2：信息架构

### R-08 详情页补齐文件操作
- 关联：F-21
- 动作：详情页顶部或底部增加“更多”入口，复用首页的重命名/移动/删除/导出/分享；删除与移动仍走确认。
- 预期：文件管理与播放在同一页面闭环。
- 工作量：M
- 依赖：R-04（菜单分组复用）
- 验收：详情页可完成重命名、移动、删除、导出、分享。

### R-09 设置重新分组
- 关联：F-18、F-26、F-29
- 动作：一级按任务分组：播放与字幕 / 手势与反馈 / 外观 / 数据与存储 / 关于；把“显示”并入外观，把“导入”并入数据与存储，关于降为独立入口；单选项页面不再单独成页。
- 预期：一级入口从 7 个减到 4–5 个，每个页面内容量均衡。
- 工作量：M
- 依赖：R-01
- 验收：不存在只有一个控件的设置页；一级入口点击后至少有 2 个可操作项。

### R-10 多选与批量操作
- 关联：F-41
- 动作：长按进入多选，顶部切换为 `SelectionTopBar`（已有组件），支持批量删除/移动/导出；退出多选恢复普通列表。
- 预期：批量整理 10 个文件从约 60 次点击降到 10 次以内。
- 工作量：M–L
- 依赖：R-04、R-08
- 验收：多选状态下批量删除有数量确认；返回键退出多选而不是退出应用。

## 阶段 3：设计系统收敛

### R-11 一套顶栏、一套对话框
- 关联：F-30、F-32、F-31
- 动作：首页迁移 `AppTopBar`；删除 `FilterChipRow`、`ClickableSettingRow`、`PrimaryActionButton`、`MediaCardData`（若确定不再恢复网格首页）；首页删除改用 `ConfirmDialog`。
- 预期：顶栏/对话框只有一处实现。
- 工作量：S
- 依赖：R-04
- 验收：全仓无重复顶栏；删除对话框只有一份代码。

### R-12 播放器 Token 化
- 关联：F-34、F-35、F-36
- 动作：定义 `PlayerTokens`（背景、强调色、文字层级、间距、控件尺寸）；从主题派生明暗；触控目标统一 ≥48dp（视觉可小、热区扩大）；圆角统一为 8/12/16/28 四档。
- 预期：播放器与其他页面共享色板来源；触控合规。
- 工作量：M
- 依赖：无（与 R-02 同批）
- 验收：播放器无原始 `dp` 值（除 Token 文件）；触控目标检测通过；强调色只在一处定义。

### R-13 选中与图标规则
- 关联：F-16、F-35
- 动作：写明“导航/操作=Outlined，媒体传输=Filled”；面板选中用勾+高亮，未选用中性图标；模式项用 Repeat/RepeatOne/Shuffle 区分；文件行按视频/字幕/文本区分图标。
- 预期：勾选重新代表“选中”；图标语义稳定。
- 工作量：S
- 依赖：R-02
- 验收：任一面板中勾选数量等于选中数量（0 或 1）。

## 阶段 4：布局与可访问性

### R-14 详情信息分组与数值表单
- 关联：F-25、F-15、F-26
- 动作：信息表按文件/视频/音频/播放记录四组；chips 与表格去重；数值设置改成点击弹出面板或步进器。
- 预期：查找单个属性更快；设置页滚动减少。
- 工作量：M
- 依赖：R-01、R-09
- 验收：详情页信息分组可见；设置页单屏至少 6 个可操作项。

### R-15 开关语义与复制反馈
- 关联：F-33、F-40
- 动作：`SwitchRow` 改为 `toggleable(role = Switch)`，内部 `Switch(onCheckedChange = null)`；复制地址统一 Snackbar/按钮文案变化。
- 预期：读屏只出现一个开关目标；复制有明确反馈。
- 工作量：S
- 依赖：无
- 验收：TalkBack 聚焦开关行只有一个可切换节点；复制后按钮显示“已复制”。

### R-16 验证矩阵补全
- 关联：F-27 及未覆盖项
- 动作：真机复验横屏渲染；补平板/折叠屏、字体 2.0、横屏设置页、导入任务与导出对话框截图；确认系统媒体通知与锁屏文案。
- 预期：把“待验证”清零或转为缺陷。
- 工作量：M
- 依赖：R-12（播放器尺寸调整后）
- 验收：每项有截图或录屏证据，结论记录在 `findings.md` 状态列。

## 不建议做的事

- 不要为了填满“显示/关于”页面而增加无实际作用的开关（例如重复的动画/密度选项）。
- 不要把播放器改成浅色或跟随主题；媒体场景保持深色是合理选择，只需统一色板来源。
- 不要恢复已下线的媒体库/网格首页来“利用”死组件；先明确产品方向，再决定删除或复用。
- 不要在未验证真机前重构横屏渲染链路；F-27 先定性再加修复。
- 不要一次性迁移全部 767 条文案；按页面分批，避免大范围回归。
