# 播放操作、字幕记忆与设置导航

状态：已实现。影响范围：1.1.0（10100），`feature:player`、`core:playback`、偏好设置、Room、设置页与根导航。本版未替换 `libplayer.so`；文件管理及导入变更见 [0025](0025-private-file-and-import-integrity.md)。

## 观看时的控制

- 双击左侧按设置步长快退，右侧快进，中央切换播放/暂停。分区取手势层实际宽高：竖屏三等分，横向连续拓宽中央区，到 2:1 时为 30% / 40% / 30%。只有尺寸未变、两次点在同一区且满足系统双击时间与距离阈值才触发；连续点不同区不误跳。锁定及控件原有交互优先。
- 播放器把应用内即时反馈和预览集中到手势区高度约四分之一处：亮度、音量（包括硬件音量键）、跳转、临时倍速、手势/滑块进度、错误和重播反馈共用位置；上下限避开系统安全区及顶部按钮。不移动系统通知或媒体控制。底栏在底部和横向安全区之内另留内容间距；「剩余」显示非负时长，片尾为 `00:00`，未知时长不伪报可跳进度。
- 画面比例仅从「更多 → 画面比例」进入；顶栏仍可一键旋转。暂停时旋转/改变 Surface 尺寸后，请求 MPV 重新呈现当前位置，不靠短暂播放、跳一帧或重开媒体来填黑屏。
- 常规与默认播放速度为 **0.25–8×**，长按临时速度为 **1.5–8×**；左下倍速菜单可选 4×、6×、8×，保留小数档精度。范围由 `PlaybackSpeedLimits` 统一，覆盖设置读写、播放器、Media3 请求和 libmpv；松手恢复前一档。滑动进度的加速倍率是另一条规则，没有随倍速上限改动。

## 字幕：全局外观、每片同步

播放中的字幕面板可选择轨道、查看完整的外挂文件名（不暴露私有路径）、调节/重置延时，也可打开上部外观控件，直接看视频中的字幕变化。设置与播放器复用字号、字体、字形、字色、背景和垂直位置六项；背景除无/半透明黑/黑色外可选深蓝，垂直偏移正值向上。外观写入 DataStore，旧用户的已有选项保留，未设置的新项采用兼容默认值。

外观由当前 libmpv 实例应用，不是 Compose 画的一行预览字。普通文本轨使用所选样式；ASS/SSA 默认保持原编排，显式覆盖时改按纯文本样式绘制，关闭覆盖恢复原编排。位图字幕不是可重新排版的文字；应用不安装字体或修改字幕源文件。

延时与选轨属于当前媒体。`media.subtitleDelayMs` 由 Room 2→3 显式无损增加，默认 `0`；旧 1→2 的选轨迁移保留。每次只按媒体 ID 更新延时列，不拿旧实体覆盖其他信息。快速微调、重置与切片按提交次序处理；切换到另一部或重开时加载该片的值，而不是沿用上一部的校正。

## 导航与断点

- 冷启动默认首页。首页和设置是两个平级根；切换标签不叠加访问历史。设置一级按系统返回离开应用回桌面，不先回首页；二级返回本级的上级。首页先退出多选或返回上个文件夹，导入/导出确认继续由原组件处理。
- 根 `NavHost` 显式关闭普通及预测返回时应用内页面的进、出过渡，不拦截系统返回手势，不改变对话框自身交互、媒体停服或后台工作。首页、设置、详情的应用内 Snackbar 放在实际顶栏下方，不盖返回控件或占用底边。
- 设置一级三组七页：观看（播放、字幕、手势与控制），文件（文件导入、存储与清理），应用（外观、关于）。
- 两个相互依赖的断点开关合为「不记录」「仅记录，从头播放」「记录并续播」。兼容读取旧设置，切换时原子保存整种策略。续播依据实际保存的位置；已知时长且进度达到 98% 视为看完，下次从头播放。不把正在运行的会话强行跳回开头，不把断点设置等同于删除播放历史。

## 回归入口

- `SubtitleDelayMigrationInstrumentedTest` 在 UUID 命名的临时库用生产迁移链分别从 v1、v2 打开，核对旧媒体/历史/选轨保留及两部视频的延时互不影响。
- `SubtitlePreferencesDataStoreInstrumentedTest` 使用临时偏好文件，关闭并重新打开存储，覆盖旧键、新外观、无效值以及两种倍速的各自上下限。
- `PlaybackSessionPreferencesInstrumentedTest` 覆盖快速调延时、重置、切队列/重建后的分片恢复、DataStore 首次和实时样式及临时倍速恢复。`MpvSubtitleRenderingInstrumentedTest` 则以真实 Surface 的 PixelCopy 检查 SRT 字体/字形/字号、底色合成、位置和原生 ASS 的覆盖/撤销；两类断言不可相互替代。
