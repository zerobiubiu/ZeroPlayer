# Wi-Fi 权限恢复路径与统一复制反馈（阶段 2F）

状态：已执行。影响范围：`feature/importer` Wi-Fi 面板；版本号。

## 背景

UI/UX 审计阶段 2F 修复两个问题（保留 F-09 风险块）：

- **F-13（P2）**：局域网权限拒绝后只提示“请在系统设置中允许后重试”，没有跳转按钮，也没说明权限名称。
- **F-40（P2）**：复制地址反馈因系统版本而异 —— API <33 弹 Toast“地址已复制”，≥33 仅写剪贴板无任何提示。

## F-13 权限拒绝恢复路径

- 权限拒绝文案补充权限名称：“未获得局域网权限。请在系统设置中允许‘附近的设备/本地网络’后重试。”
- 拒绝后在提示下方新增 **“去设置”** 按钮，跳转 `Settings.ACTION_APPLICATION_DETAILS_SETTINGS`（本应用详情页）；返回后可再次点击“启动服务”重试（权限检查在启动时重新执行）。
- 跳转用 `runCatching` 兜底，个别 OEM 设置页不可直达时不崩溃。

## F-40 统一复制反馈

- 删除 Toast 与 API 分支；所有版本统一：复制后按钮文案变为 **“已复制”**，2 秒后恢复“复制地址”（`LaunchedEffect(copied) { delay(2000) }`）。
- 反馈为按钮内联文案变化，读屏可感知（按钮文本即状态），不依赖 Toast。
