# 首页头部去重与统一顶栏、目录行与移动路径（阶段 2B）

状态：已执行。影响范围：`core/design` AppTopBar 与移动对话框文案；`feature/home` 顶栏/面包屑/目录行；相关单测；版本号。

## 背景

UI/UX 审计阶段 2B 修复五个问题（按 F-01→F-24→F-30 顺序，同头部一次定稿）：

- **F-01（P2）**：首页大标题“文件”与面包屑首段“文件”同义重复，像两行标题。
- **F-24（P2）**：标题+面包屑占约 120dp；面包屑祖先用 TextButton（默认 48dp 高+内边距）。
- **F-30（P2）**：首页自建 TopAppBar，与其他页 AppTopBar 双实现。
- **F-23（P2）**：目录行两行高度只显示“目录”占位，无有效信息。
- **F-04（P2）**：移动对话框把内部根目录名“文件”当路径展示（“当前位置：文件”）。

## F-01 / F-24 / F-30 首页头部

- **F-30**：`AppTopBar` 新增 `titleContent` 可选插槽（默认仍为标题+副标题）；首页 `HomeTopBar` 改用 `AppTopBar`，删除自建 `TopAppBar`，全应用一套顶栏实现与内边距。
- **F-01**：标题改为**当前文件夹名**（根目录为“文件”）；面包屑只含**祖先路径**（根段“文件”+各级祖先），不含当前文件夹，消除“文件/文件”重复。纯逻辑抽为 `homeTitle` / `breadcrumbSegments`（`HomeHeader.kt`），可 JVM 单测。
- **F-24**：面包屑并入顶栏标题区（标题+祖先路径两行紧凑文本），删除独立面包屑行；祖先用紧凑 `Text` + `clickable`，`defaultMinSize(minHeight = 48.dp)` 保证热区 ≥48dp；横向滚动保留。顶部固定开销由约 120dp 降至顶栏单区（≤~88dp）。

## F-23 目录行单行

`FileTreeRow` 目录行 `supportingContent = null`（单行），不再显示“目录”占位；文件行保留“文件 · 大小”。目录与文件行高不再为无效副信息浪费两行。

## F-04 移动对话框路径

`design_move_current_root` 改为“当前位置：根目录”；`design_move_current_path` 改为“当前位置：%1$s”（真实相对路径，不再冠以内部根名“文件”）。根目录与子目录均可理解。
