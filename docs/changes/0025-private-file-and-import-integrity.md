# 删除确认、导入暂存与私有字幕完整性

状态：已实现。影响范围：1.1.0，首页、详情、Wi-Fi 网页、本机导入、文件树删除日志及 `core:storage`。本次不修改文件树及导入日志格式，不迁移外部来源。[0026](0026-player-subtitles-and-navigation.md) 另记字幕延时所需的 Room 升级及本版公共验收。

## 删除的是确认时的对象

首页长按进入选择模式：选一项时可直接重命名，点「更多」访问该类型可用的详情、传输、移动和删除；选多项时可批量移动、删除。没有重新加回每行常驻的三点按钮，读屏仍有直接打开菜单的操作。详情的「更多」从当前文件树条目取得快照，不再用媒体信息拼出一个只有路径的目标。

- 首页单项、批量与详情删除传递选中时的路径、文件类型、设备号和 inode。数据层在同一私有树锁里以 `lstat` 重验，再写删除日志、移走内容、提交数据库。原路径消失、类型变化或身份不符时提示重新选择；不会查一次新身份继续删。批量按项返回结果，一个项目成功不会使同批未变项目失效。
- 网页列表返回的 `device`、`inode` 是十进制字符串；确认框连同原条目的路径和类型原样发送。缺参、旧版只有路径的请求和身份冲突均不执行删除；网页保留错误原因。此机制防误操作，不是对无鉴权 Wi-Fi 服务的访问控制。
- 设备号与 inode 是同一私有文件系统内的对象身份，不是跨重装或永久不复用的 UUID。

## 删除提交后清字幕，失败不删原件

文件树删除日志原已记录受影响媒体的 ID。只有在 Room 已提交删除后，正常收尾和中断恢复才按这些 ID 清理 `files/subtitles/<mediaId>/`，再移除删除日志。即使原删除暂存已被清走，仍能重试字幕清理。事务回滚会恢复原文件并保留私有字幕；单删视频不连带删除同目录用户 `.srt`。选择整个文件夹时，夹内文件按这次明确的选择处理。

详情页添加字幕先在同一私有字幕目录创建不可列为字幕轨的 `.part`，流式写入并同步，在树锁内为完整文件选取不冲突的名称并原子改名。失败只清理本次暂存；其他字幕和并发导入的同名内容均不覆盖。

## 取消、放弃与移除记录

| 操作 | 保留与清理边界 |
|---|---|
| 取消本机导入 | 有断点时保留复制内容并转为可重试的失败任务；不会把取消当作已授权销毁。 |
| 放弃并清理 | 仅本机失败或已取消任务提供二次确认。取消确认不派发清理。确认后持任务执行锁、再持树锁，检查来源、状态、暂存路径、提交日志及媒体记录；旧缓存路径还须排除其他任务占用。 |
| 已改名、尚未入库的本机暂存 | 只有目标确属日志中的设备号/inode 和长度且没有媒体记录，才退回本任务暂存。先移除已不再需要的提交日志，再清完成标记和暂存，最后删任务记录；中断后不会留下指向已删暂存的提交日志。 |
| 网页已收到的文件 | 保存失败或取消仍可重试/从网页下载，不能借手机端的本机放弃入口清掉它。 |
| 移除已完成记录 | 只收尾任务日志并移除记录；不删除已入库或已保存的正式文件。 |

归属不明、文件类型冲突、目标已入库或清理失败时保留任务并反馈原因。外部 SAF/分享来源始终只读。

## 回归入口

- `FileTreeConsistencyInstrumentedTest` 用真实文件和隔离 Room 验证同名替换（含文件/目录互换）、批量兄弟项、已提交及回滚路径上的专属字幕，以及中断的字幕流与另一份同名导入互不覆盖。
- `LocalDiscardInstrumentedTest` 验证普通取消、明确放弃、确认目标冲突、旧暂存归属、已入库/网页保护及清理重试；`ImportTasksDialogInstrumentedTest` 验证二次确认的取消与执行。
- `HomeViewModelTest`、`FileMenuAndDetailActionsInstrumentedTest` 覆盖手机选择与操作反馈；`WebDeleteTargetTest`、`WebDeletePageInstrumentedTest` 覆盖网页协议及打包页面。
