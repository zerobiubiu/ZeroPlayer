# 关于页技术信息归位、导入通知列表化与错误态恢复（阶段 2D）

状态：已执行。影响范围：`feature/settings` 关于页；`app` 导入任务对话框与错误分类；`core/design` ErrorState；`feature/home` 错误态接线；相关单测；版本号。

## 背景

UI/UX 审计阶段 2D 修复三个问题：

- **F-08（P2）**：关于页暴露 `libplayer.so`/`assets/...`/“硬解待实机验证”等实现与开发状态信息。
- **F-12（P2）**：导入通知 `joinToString("\n")` 合并成一段；失败任务直出原始错误文本。
- **F-39（P2）**：错误态文案固定“可能已被移动或删除”（chmod 000 权限错误也误报），且只有“重试”，没有文案承诺的“返回上级”。

## F-08 关于页技术信息归位

- 版本信息只保留 **版本 + 播放引擎名**（libmpv）；删除“引擎状态”行（含 `.so`/FFmpeg/“待实机验证”等开发状态）。
- 许可说明不再暴露 `assets/third-party-licenses` 路径；新增 **“开源许可”** 按钮，点击在对话框中展示随包许可文本（NOTICE.txt + LICENSE.libmpv-android，可滚动），许可仍可访问。
- 产品说明保留（本地优先、私有存储、网页上传手动开启）。

## F-12 导入通知列表化与可行动失败

- 通知逐条渲染（每条独立 `Text` + `liveRegion`），不再合并成一段。
- 失败任务：新增纯函数 `classifyImportError`（空间不足/来源失效/读写失败/取消/通用）映射为可行动文案；原始错误折叠在“详情”按钮后，不直接主展示。
- 分类关键词为内部逻辑（登记文案门禁白名单），用户可见文案经 `messageRes` 资源化。

## F-39 错误态标题与第二动作

- `ErrorState` 增加 `title`（默认“无法读取”）与 `secondaryActionLabel/onSecondaryAction`；重试与第二动作并排。
- 首页错误文案改为只陈述事实：“无法读取此文件夹。请返回上级文件夹或重试。”（不再误报“已被移动或删除”，chmod 000 权限错误同样适用）。
- 首页在子目录时传入“返回上级”第二动作（`navigateUp`）；根目录仅重试。
