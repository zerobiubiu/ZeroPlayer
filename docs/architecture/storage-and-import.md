# 私有文件树与导入

状态：现状文档  
影响范围：`core:storage`、`data`、首页、Wi-Fi 服务、系统打开与分享

## 1. 目录布局

```text
files/
  media/                   首页和网页共用的文件树：视频、字幕与其他文件
  subtitles/<mediaId>/     详情页单独导入的字幕副本及旧版字幕
  import-staging/          本机选择/分享文件的持久暂存及完成标记
  import-commits/           导入目标与 dev/ino 文件身份日志
  web-uploads/             网页接收的暂存文件与接收日志
  backups/.file-tree-operations/  文件操作恢复日志
cache/
  thumbnails/              缩略图缓存
  temporary/               旧版导入暂存；受保护的未完成任务不清理
  image_cache/             Coil 缓存
```

`media` 表的 `relativePath` 相对于 `filesDir`；文件树接口的路径相对于 `files/media`，空字符串表示根目录。用户只在首页和网页操作该树，应用不申请媒体库读取权限，也不扫描系统媒体库或外部目录。

历史版本的逻辑文件夹和播放列表记录留在数据库内，不再成为界面概念；原视频没有被自动移动。旧网页上传可能以 UUID 命名磁盘文件，列表显示原始名称，但操作和持久路径仍指向原文件。用户主动重命名时才改变磁盘名称。

## 2. 本机和系统分享导入

1. 首页「+」使用 Storage Access Framework 选择一个或多个文件；系统 `ACTION_VIEW`、`ACTION_SEND`、`ACTION_SEND_MULTIPLE` 接收来源 URI。
2. 读取文件名、可用大小和 MIME；保留读授权，写入 Room `import_tasks` 并调度 WorkManager。目标文件名冲突时采用不覆盖的名称。
3. 通过 1 MiB 缓冲流式复制到 `files/import-staging`，周期性同步文件并保存字节进度。复制结束、大小校验及数据同步后写入完成标记。
4. 在共享文件树锁内确认目标父目录存在且没有同名文件，先同步提交身份日志（源文件的 dev/ino、大小及目标路径），再执行同文件系统原子改名，并在 Room 事务中保存视频元数据和任务状态；失败时按身份退回暂存，重启后不会接管其他同名文件。普通文件和字幕不强制解析视频。
5. 视频系统探测失败时仍保留原文件与未知元数据，实际能否播放由 libmpv 判定。启用重复检测时，按大小与首段哈希提示“可能重复”，仍保留副本。
6. 外部「打开」只在私有复制完成且取得内部视频 ID 后进入播放器；分享导入不自动播放。来源文件始终只读，不移动、不修改、不删除。

完成标记与任务记录使已复制完毕的文件不再依赖外部 URI 的临时授权。仍在复制的任务可在授权仍有效时续传；续传前逐块核对暂存前缀，来源变化或授权失效时明确失败并要求重新选择或重新分享。新暂存不在缓存清理范围；旧版 `cache/temporary` 中进行中或待重试的任务暂存也会保留。

## 3. Wi-Fi 文件服务

- 用户手动启动前台服务，绑定当前局域网 IPv4 固定端口 `8765`，浏览器访问 `http://手机IP:8765/`。服务和网页资源均随 APK 打包。
- 首页浮层提供启动、停止、初始目录、可用空间、导入设置及本次上传记录；关闭浮层不停止服务。网页可在私有文件树中浏览、上传任意文件（包括零字节文件）、下载、创建目录、重命名、移动和删除。
- 接收使用 1 MiB 缓冲写入 `files/web-uploads/<任务ID>.part`；完成接收和同步后入队，网页和浮层分别显示传输与保存状态。接收日志覆盖“接收完成但任务尚未入库”的进程中断；恢复时保留完整暂存并重试入队。
- 浏览器传输尚未完成就中断时，需要重新上传。已接收但保存失败的任务保留暂存，可在网页重试保存或下载暂存；用户停止服务不取消已经入队的任务。
- Android 17 且 targetSdk 37 时按需请求 `ACCESS_LOCAL_NETWORK`。端口被占用或没有局域网地址时显示错误。
- 服务没有登录、令牌或加密；所有能连接该地址的设备都可读写和删除文件。传输结束后手动停止，只在可信网络临时使用。

## 4. 文件操作和一致性

`FileTreeRepository` 是首页和网页的统一入口。路径以规范化私有根目录为边界，不跟随符号链接，拒绝向树外访问和覆盖同名项目。真实文件和非空目录可以重命名、移动与删除。

文件树写操作与导入最终提交共享互斥锁；修改关联视频时同步 Room 的相对路径及关联记录。操作日志和补偿处理覆盖进程中断；已移入正式位置但尚未完成入库的导入会暂时阻止相关文件树修改，避免恢复时写入旧路径。Android 实测拒绝应用创建硬链接，提交不再依赖该能力，也不会为提交再次复制大文件。日志不保证设备突然断电时目录项已经持久化。

同目录与视频同基名、可带语言后缀的字幕会交给播放器；原有 `files/subtitles/<mediaId>/` 字幕继续生效。视频与字幕只从应用私有目录交给 libmpv，不播放外部来源 URI。

## 5. 导出与分享

首页长按文件可导出或分享。导出通过系统文档选择器选择目标，用固定 1 MiB 缓冲流式写入；取消或失败时目标位置可能保留未完成文件。分享使用仅暴露 `files/media/` 的非导出 `FileProvider` 和临时读取授权；数据库和暂存不对分享方开放。

## 6. 空间与失败语义

- 入队时对已知大小检查可用空间并预留 256 MiB；大小未知时依赖写入错误反馈。容量按 1024 进制显示 `KiB`、`MiB`、`GiB` 和 `TiB`。
- 应用被系统回收时保留复制断点；用户主动取消本机任务会清理其暂存。网页已接收文件取消保存后保留，可重试或下载。
- 目标目录消失或出现同名冲突时，任务失败并保留暂存，不自动重建目录或覆盖已有文件。
- 清缓存不删除正式文件和待恢复的旧版暂存；容量统计包括视频、字幕及其他文件，不跟随符号链接。
- 大文件从来源到暂存及导出均为流式处理；实际可用空间、存储性能和来源 URI 授权仍是运行约束。
