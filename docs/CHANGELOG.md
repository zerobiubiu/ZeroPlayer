# 版本变更

## 1.0.4

- 播放器顶栏“画面比例”与“旋转屏幕”归位：比例入口改用比例图标并打开比例面板；旋转成为顶栏独立按钮，一次点击切换横竖屏；“更多”面板不再保留第二个旋转入口。
- “播放列表”面板改为真实“播放队列”：列出当前目录队列条目（仅显示文件名），当前播放项高亮带勾，点击其它条目即跳转播放；打开面板自动定位到当前项，长队列限高滚动，空队列给出空状态提示。
- 队列跳转经受控 API 执行：无效索引、重复目标与快速连点均为无操作，切换与上一集/下一集共用同一切源门，系统媒体会话生命周期不变；上一集/下一集与播放模式保留。

## 1.0.3

- 播放器面板统一选中语义：倍速/画面比例/音轨/字幕/播放模式仅当前项显示勾选并高亮，动作与导航项不再带勾选标记。
- 修复打开播放器面板时系统状态栏重新出现的问题：面板在自己的窗口内保持沉浸式，退出播放页后恢复系统栏。
- “更多”面板移除禁用的“播放引擎”技术行；引擎信息仍可在 设置·关于 查看。

## 1.0.2

- 设置页统一为即时保存：开关与数值采用同一语义，删除每行右侧的“保存”按钮。
- 数值在键盘完成或失焦时写入；非法值不写入并提示允许范围，失焦时恢复为上次有效值。
- 连续修改同一项时按顺序落盘，最后一次修改不会被覆盖；保存失败会弹出提示而不是静默失败。

## 1.0.1

- 关闭播放页（返回）会立即停止播放并释放引擎；按主页键退到桌面时仍保留后台播放。
- 记住每个视频上次选中的字幕轨（含关闭字幕），下次打开自动恢复；选择写入媒体表，数据库升级到 v2 并提供迁移。
- 播放页按参考图重排：顶部为返回、片名、画面比例、字幕与更多；底部为时间/剩余、进度条、倍速、快退、播放暂停、快进与播放列表。
- 异形屏适配：视频可进入缺口区域铺满屏幕，顶部与底部控件按安全区避让。
- 横向滑动进度取消固定 30 秒上限：跳幅随距离增长，并按手势峰值速度放大 1×～16× 档（刻度 1/2/5/10/20 秒），慢滑仍逐秒微调。
- 设置页改为分组入口 + 二级页面；新增「滑动进度震动反馈」开关，适配无线性马达或震感不佳的设备。
- 移除动态取色（Android 12+ 壁纸配色），统一使用应用自带配色。

## 1.0.0

- **开源发布**：项目以 GPL-3.0-only 公开，补充第三方组件声明与源码/重新链接材料说明；推送 `vX.Y.Z` 标签即自动构建、签名并在 GitHub Releases 发布 ARM64 安装包。
- 更换应用图标：白色立体丝带零形与播放负空间，自适应图标配单色主题图层。
- **不兼容变更**：安装包和原生构建仅支持 `arm64-v8a`；不再提供 32 位 ARM、x86 和 x86_64 原生库。
- 保留原应用 ID 和 ARM64 播放库；在支持 ARM64 的设备上覆盖安装不会因本次架构筛选主动迁移或清空私有数据。
- 本次主版本递增由架构兼容范围变化触发，不表示已经完成 ARM 真机和硬件解码验证。详见 [ARM64 专用打包](changes/0004-arm64-only.md)。
- 首页改为真实私有文件树；移除媒体库、收藏和播放列表入口，保留旧数据。点击视频播放，长按管理、详情、导出或分享。
- 加号菜单支持本机和 Wi-Fi 导入；局域网文件服务使用固定 8765 端口与根地址，无登录或令牌，可上传任意文件并浏览、下载和管理目录。
- 导入继续使用流式复制与持久任务；完整暂存在进程终止后可恢复，疑似重复视频保留副本并提示。
- 播放器加入小步进虚拟滑动预览与触觉反馈，字幕默认位于视频画面下侧；音量键显示百分比，临时倍速请求不阻塞界面主线程。
- 引入 AndroidX Media3 Session / Common 1.11.1，系统会话与界面共享唯一 libmpv；不引入 ExoPlayer。播放服务负责后台生命周期、音频焦点和播放时唤醒。
- 暂停后跳转也及时保存断点，不依赖退出播放器来触发释放或保存，跳转不重复累计播放次数。

## 0.3.0

- 应用更名为 ZeroPlayer，重绘 Android 自适应图标及单色主题图标；保留原应用 ID。
- 应用与网页上传的容量标签改为 KiB、MiB、GiB、TiB，保留原有 1024 进制计算。
- 将模拟播放器切换为真实 libmpv：Surface 视频画面、音频输出、进度、音轨和字幕均由引擎驱动。
- 将 libmpv、FFmpeg 等静态链接到随 APK 提供的 JNI 库；支持四种 Android ABI，无需安装额外播放库。
- 修复播放控件、后台暂停、临时倍速和进度保存；详情页标明导入阶段的轨道探测可能不完整。
- 设备回归任务默认禁止直接执行，避免 Gradle 测试收尾卸载应用并清空私有媒体。
- 模拟器验证软件回退、轨道切换与字幕渲染；物理设备硬解仍待验证。详见 [libmpv 播放接入](changes/0003-libmpv-playback.md)。

## 0.2.0

- 新增手动启停的局域网网页上传：静态页面随 APK 打包，大文件流式接收后进入持久化导入队列。
- Android 17 上按需请求局域网访问权限；服务使用临时令牌并提示 HTTP 明文风险。
- 设置页枚举改为下拉菜单，数字改为范围校验后的手动输入。
- 修复 KSP 增量构建可能遗漏 Hilt 绑定的问题。
- 详细实施与验证见 [网页上传与设置输入](changes/0002-web-upload-and-settings.md)。

## 0.1.0

- 初始 Android 工程、媒体库、SAF 导入、设置和预览播放引擎。详见 [初始实现](changes/0001-initial-implementation.md)。
